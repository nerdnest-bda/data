# Youniversity
Big Data Project

## How to use the scraper
The scraper is present in the file `scraper.py`. It's advised to run the scraper on Google Colab so that you will not run into resource issues.

Change the range of pages you want to scrape on line 88 of the python file. As our first iteration we will be extracting 320 pages each. So your range should be (1, 321), (321, 641), (641, 961), (961, 1281)
